Juego "Adivina la Palabra" en Java

PROGRAMACIÓN

•Interfaz gráfica. Uso de Java Swing para crear una pantalla de outputs e inputs dónde se desarrolle el juego.
•Diseño de un sistema de selección aleatoria. Las palabras de cada juego se aleatorizan cada vez que se juega para dar más profundidad y rejugabilidad.
•Producto finalizado como un .JAR para poder ser ejecutado como archivo independiente.

En navidad, el centro de estudios de Digitech nos propuso la actividad de diseñar un Escape Room con diferentes pruebas. Yo quise cumplir la propuesta con la creación en Java de un juego de adivinar palabras.

Se te muestra un grupo de palabras, de las cuáles eliges una. Si la palabra es la ganadora, el juego finaliza, si la palabra es errónea, el juego te dice cuántas letras están en la misma posición que en la palabra ganadora. Tienes 5 intentos por partida.



Tenemos 3 procesos interesantes:
•De un diccionario de palabras se cogen sólo un grupo de 16, creado aleatoriamente para cada partida.
•La palabra que escoges se compara con la ganadora y te devuelve cuánto se parecen.
•El juego acaba cuando ganas 3 partidas consecutivas. Al perder, la racha se reinicia.
